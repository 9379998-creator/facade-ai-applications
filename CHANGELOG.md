# Журнал изменений (Changelog)

Все заметные изменения в проекте «Facade AI Applications» фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [0.1.0] - 2026-10-07

### Добавлено (Added)
- Первичная инициализация публичного репозитория и архитектурного каркаса.
- Статическое приложение на React 19 + TypeScript + Vite.
- 12 навигационных разделов архитектурной презентации с валидацией через Zod.
- Базовый модуль коммерческого отдела: кейс приёмки входящего тендерного пакета (`commercial-tender-package-intake`).
- Синтетический проект «Северный порт» (Northern Port) с базовым паспортом, захватками и системами.
- Навигация с клавиатуры (стрелки, клавиша M для вызова карты).
- Модальная интерактивная карта разделов с индикацией статусов реализации (`WORKING`, `PROTOTYPE`, `CONCEPT`, `TBD`).
- Автоматизированные проверки:
  - `scripts/validate-content.mjs` (валидация контента);
  - `scripts/scan-sensitive-data.mjs` (поиск секретов и персональных данных);
  - `scripts/check-large-files.mjs` (контроль файлов >10MB).
- Тестовое покрытие: модульные тесты Vitest и E2E тесты Playwright (настольный и мобильный 375px режимы).
- Настройки CI GitHub Actions (`validate.yml`, `secret-check.yml`, `dependabot.yml`).
- Шаблоны GitHub Issues и Pull Request.
- Базовая документация: Устав проекта, Видение, Дорожная карта, Требования, Архитектурные решения (ADR 0001–0004), Глоссарий, Статус лицензирования.

# Руководство по участию в проекте (Contributing Guide)

Мы приветствуем предложения по улучшению архитектуры, добавлению отраслевых кейсов и алгоритмов фасадного инжиниринга!

## Как предложить изменения

1. **Создайте Issue**: используйте соответствующий шаблон (`business-case.yml`, `presentation-section.yml`, `demo-defect.yml` или `research-task.yml`).
2. **Создайте ветку**: для новых функций используйте префикс `feat/`, для исправлений `fix/`, для документации `docs/`, для служебных задач `chore/`.
3. **Строго соблюдайте политику данных**: проверьте, что ваши изменения не содержат коммерческих тайн, реальных цен или персональных данных (см. [docs/05-data-policy.md](docs/05-data-policy.md)).
4. **Проверьте код локально**: выполните команду `npm run validate`.
5. **Откройте Pull Request**: заполните предложенный шаблон и дождитесь ревью владельца проекта.

# Facade AI Applications

> **Прикладной искусственный интеллект для полного жизненного цикла фасадного проекта**

Интерактивные приложения, алгоритмы и архитектурная презентация для демонстрации роли прикладного искусственного интеллекта и детерминированных инженерных алгоритмов на всех этапах работы фасадной строительной компании: от тендерной документации до строительной площадки и сдачи исполнительной документации.

## Статус проекта

Проект находится на этапе первичной инициализации архитектурного каркаса (`chore/bootstrap-project`).

Подробное описание архитектуры, сценариев и правил работы доступно в каталоге `docs/`.

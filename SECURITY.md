## Сообщение об уязвимостях и утечках данных

Безопасность является ключевым приоритетом данного публичного проекта.

Если вы обнаружили потенциальную уязвимость безопасности или случайную публикацию чувствительных данных (секретов, токенов, фрагментов реальной конфиденциальной информации):

1. **НЕ создавайте публичный Issue**.
2. Воспользуйтесь функцией **Private Vulnerability Reporting** на вкладке Security репозитория GitHub:  
   `https://github.com/9379998-creator/facade-ai-applications/security/advisories/new`
3. Либо направьте защищённое сообщение владельцу репозитория.

## Принципы реагирования на утечки

- Случайно скомпрометированные API-ключи и токены подлежат немедленному отзыву в соответствующем сервисе.
- Простое удаление файла новым коммитом **не удаляет** секрет из истории Git. При подтверждении утечки история Git должна быть очищена с помощью инструментов фильтрации репозитория.

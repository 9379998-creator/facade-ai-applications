# Устав проекта «Facade AI Applications»

> **Полное название**: Facade AI Applications  
> **Русский подзаголовок**: «Прикладной искусственный интеллект для полного жизненного цикла фасадного проекта»  
> **Имя репозитория**: `facade-ai-applications`  
> **Владелец репозитория**: `9379998-creator`  
> **Сквозной синтетический демонстрационный объект**: «Северный порт» / Northern Port  
> **Статус документа**: Утверждён в рамках базовой инициализации (Revision 1.0)

---

## 1. Главная цель проекта

Создание отдельного публичного веб-приложения и интерактивной презентационной платформы для демонстрации реального применения прикладных алгоритмов, специализированного ПО и искусственного интеллекта на каждом этапе жизненного цикла фасадного строительного объекта.

Проект ориентирован на широкую аудиторию участников строительного процесса (инженеров, сметчиков, снабженцев, начальников участков, финансистов и топ-менеджмент), не являющихся специалистами по машинному обучению.

## 2. Ключевая концепция

> **«Искусственный интеллект не должен становиться ещё одной сложной программой или обязательным чатом. Он должен работать внутри понятных отраслевых приложений. Сотрудник загружает документы или вводит данные, нажимает понятную кнопку, проверяет результат и получает таблицу, расчёт, документ, отчёт, предупреждение или управленческое решение».**

## 3. Целевые подразделения компании

1. **Коммерческий отдел** — приёмка тендерных пакетов, ведомости объёмов (ВОР), предварительная себестоимость, риски и КП.
2. **Конструкторский отдел** — проверка исходной архитектуры, согласование КМ/КМД, спецификации, раскрой, коллизии.
3. **Отдел снабжения** — связка счетов и номенклатур, анализ цен, графики поставок под монтажные захватки.
4. **Служба логистики** — упаковочные листы, комплектовочные ведомости, отслеживание партий, транспортная загрузка.
5. **Производство** — раскрой профиля и кассет, маркировка, ОТК, балансировка загрузки станков.
6. **Строительная площадка** — приёмка конструкций по QR/меткам, фиксация монтажа по захваткам, фотофиксация дефектов.
7. **Руководитель проекта (РП)** — сквозной план-факт, контроль сроков, увязка смежников, предиктивный анализ задержек.
8. **Финансово-экономическая служба** — кэш-флоу, план-факт себестоимости, рентабельность систем.
9. **Бухгалтерия** — сверка первичных документов, УПД, КС-2 / КС-3, налоговые риски.
10. **Служба качества (ОТК)** — входной контроль материалов, паспорта качества, журналы дефектов.
11. **Исполнительная документация** — реестры актов скрытых работ (АОСР), исполнительные схемы, паспорта фасада.
12. **Руководство компании** — сводный дашборд портфеля объектов, маржинальность, стратегические риски.

## 4. Базовые принципы и ограничения

1. **Публичность и безопасность**: Репозиторий является публичным (`PUBLIC`). Запрещено коммитить персональные данные (ПДн), реальные коммерческие тайны, цены, закрытые чертежи и проприетарные данные заказчиков.
2. **Синтетический объект**: Все демонстрации проводятся на вымышленном синтетическом объекте «Северный порт».
3. **Честность статусов**: Каждый модуль строго классифицируется статусами `WORKING`, `PROTOTYPE`, `CONCEPT`, `TBD`. Запрещено выдавать концепции или прототипы за готовые внедрённые продукты.
4. **Независимость**: Репозиторий полностью автономен и не зависит от кода внешних репозиториев (включая `fero-launcher-v4`).

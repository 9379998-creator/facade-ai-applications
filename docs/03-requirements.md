# Требования к системе (Requirements)

## 1. Функциональные требования
- **FR-01**: Возможность последовательного перехода по всем 12 разделам презентации (вперёд / назад, с клавиатуры стрелками).
- **FR-02**: Интерактивная карта разделов с прямым переходом к любому экрану и индикацией статуса реализации.
- **FR-03**: Отображение карточек кейсов с разграничением ролей человека, ИИ и классических алгоритмов.
- **FR-04**: Отображение синтетического паспорта объекта «Северный порт» с чёткой пометкой `TBD` для неподтверждённых параметров.
- **FR-05**: Фильтрация и явное цветовое/текстовое обозначение статусов (`WORKING`, `PROTOTYPE`, `CONCEPT`, `TBD`).

## 2. Нефункциональные требования
- **NFR-01**: Приложение является 100% статическим клиентским SPA (React, TypeScript, Vite) без серверного бэкенда и внешних баз данных.
- **NFR-02**: Отсутствие внешних платных AI API на этапе первой итерации.
- **NFR-03**: Поддержка экранов от 375 px (мобильные устройства) до 1920+ px (большие экраны и проекторы). Отсутствие горизонтальной полосы прокрутки на 375 px.
- **NFR-04**: Доступность (A11y): навигация с клавиатуры (клавиши стрелок, Tab, Enter), видимый фокус элементов, поддержка скринридеров через семантический HTML.
- **NFR-05**: Время загрузки первого экрана в production build < 1 сек.
- **NFR-06**: Полное разделение контента и представления (типизированные JSON-схемы контента, проверенные тестами).

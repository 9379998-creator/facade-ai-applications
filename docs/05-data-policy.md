# Политика конфиденциальности и обращения с данными (Data Policy)

## 1. Публичный характер репозитория
Репозиторий `facade-ai-applications` является публичным (`PUBLIC`). Любые файлы, попадающие в коммиты или историю веток, становятся открытыми для всего интернета.

## 2. Строгий запрет на публикацию чувствительных данных
В репозитории **категорически запрещено** публиковать:
1. **Персональные данные (ПДн)**: ФИО реальных сотрудников или контрагентов, личные телефоны, личные email-адреса, паспортные данные.
2. **Коммерческие и финансовые тайны**: Реальные договоры, акты, сметы с коммерческими расценками, маржинальность, данные о закупках конкретных контрагентов.
3. **Юридические идентификаторы**: Реальные российские ИНН, ОГРН, КПП, номера расчётных и корреспондентских счетов, банковские реквизиты.
4. **Технические секреты и токены**: Пароли, приватные ключи SSH/PGP/TLS, API-токены (OpenAI, Anthropic, Google Cloud, GitHub tokens), connection strings к базам данных.
5. **Локальные системные пути**: Абсолютные пути файловой системы, содержащие имена учётных записей пользователей операционной системы.
6. **Проприетарные чертежи и CAD-файлы**: Оригинальные DWG/RVT/IFC чертежи реальных объектов строительства без письменного согласия правообладателя.

## 3. Требования к демонстрационным материалам
1. Разрешено использовать **только синтетические данные** (вымышленный объект «Северный порт»).
2. Разрешено использовать вымышленные компании (например, `ООО "Северный Фасад Девелопмент"`).
3. Все контакты должны использовать домен `.example.internal` или `example.com`.
4. Любые числовые показатели и параметры объекта, не утверждённые владельцем, должны иметь пометку `TBD`.

## 4. Автоматизированный контроль
Перед каждым коммитом и в CI GitHub Actions выполняются скрипты:
- `npm run scan:sensitive` — сканирование на наличие паттернов утечек данных.
- `npm run check:large-files` — блокировка файлов размером более 10 МБ.

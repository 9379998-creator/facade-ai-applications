# План измерений и критерии эффекта (Measurement Plan)

## 1. Честность метрик
В рамках проекта строго запрещено декларировать неподтверждённые финансовые или временные эффекты как свершившийся факт.
Любые заявления о пользе алгоритмов делятся на две категории:
1. **Подтверждённые измерения (Empirical / Verified)** — результат замеров хронометража или двойного слепого тестирования на синтетических или пилотных проектах.
2. **Целевые гипотезы (Hypothesis / Target)** — расчётный ожидаемый эффект, требующий проверки в ходе пилота. Обязательно маркируется как гипотеза.

## 2. Метрики для коммерческого модуля (Тендерный пакет)
- **Метрика M-1 (Время первичной структуризации)**: Время от получения архива до формирования реестра актуальных листов и форматов (базовый процесс: 2–6 часов ручного разбора; целевая гипотеза: 5–15 минут машинного анализа).
- **Метрика M-2 (Полнота выявления коллизий)**: Процент расхождений между ведомостью объёмов работ (ВОР) и чертежами фасадов, обнаруженных до подписания договора (целевая гипотеза: выявление 100% явных расхождений по номенклатуре и площадям).
- **Метрика M-3 (Ошибки оператора)**: Количество ручных опечаток при переносе позиций спецификации в сметный калькулятор.

## 3. Методология замера
1. Формирование эталонного тестового пакета документации объекта «Северный порт».
2. Выполнение разбора опытным инженером-сметчиком вручную с фиксацией хронометража.
3. Выполнение разбора с помощью прикладного инструмента с участием инженера (Human-in-the-loop).
4. Сравнение времени, полноты спецификаций и количества пропущенных рисков.

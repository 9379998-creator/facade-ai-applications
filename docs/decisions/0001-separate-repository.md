# ADR 0001: Создание отдельного независимого репозитория

## Статус
Принято (Accepted)

## Контекст
Проект «Facade AI Applications» является самостоятельной долгосрочной инициативой по систематизации прикладных решений в сфере фасадного инжиниринга. Существуют сопутствующие проекты (например, `fero-launcher-v4`), решающие специализированные прикладные задачи.

## Решение
1. Создать полностью изолированный публичный репозиторий `facade-ai-applications`.
2. Не включать проект как подпапку или submodule в другие кодовые базы.
3. Полностью исключить перенос закрытых исходных кодов сторонних проектов. Прототип Launcher упоминается и интегрируется исключительно через спецификации сценариев и демонстрационные манифесты.

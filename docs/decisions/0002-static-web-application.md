# ADR 0002: Выбор статического клиентского приложения (SPA)

## Статус
Принято (Accepted)

## Контекст
Платформа предназначена для интерактивной демонстрации возможностей, навигации по отраслевым кейсам и сценариям работы специалистов. На первом этапе требуется максимальная надёжность, автономность, быстродействие и возможность бесплатного статического хостинга (например, GitHub Pages).

## Решение
1. Приложение строится на базе **React 19 + TypeScript + Vite**.
2. Серверный бэкенд, реляционные базы данных и облачные AI API на первом этапе не подключаются.
3. Вся логика валидации контента, интерактивная навигация и фильтрация статусов выполняются на стороне клиента.
4. Контент отделяется от компонентов в структурированные типизированные JSON-модели.

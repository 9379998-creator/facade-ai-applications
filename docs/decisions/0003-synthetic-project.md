# ADR 0003: Использование сквозного синтетического проекта «Северный порт»

## Статус
Принято (Accepted)

## Контекст
Репозиторий является публичным (`PUBLIC`). Использование чертежей, смет и названий реальных девелоперских объектов нарушает NDA, коммерческую тайну и законы об авторском праве.

## Решение
1. Ввести единый сквозной вымышленный московский строительный объект — **«Северный порт» (Northern Port)**.
2. Использовать типовые для современного фасадного строительства конструктивные узлы: светопрозрачные стоечно-ригельные витражи (СПК), навесные вентилируемые фасады (НВФ) с кассетами из анодированного алюминия, межоконные вставки и примыкания.
3. Все неподтверждённые технико-экономические показатели помечать как `TBD`.

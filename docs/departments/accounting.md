# Бухгалтерия (Accounting Department)

## 1. Роль подразделения
Учёт первичной документации (УПД, ТОРГ-12, счета-фактуры, КС-2, КС-3), списание материалов на объект по нормам М-29, налоговый учёт и отчётность перед регуляторами.

## 2. Ключевые проблемы
- Огромный объём бумажных первичных документов от сотен поставщиков крепежа, профиля и герметиков.
- Ошибки в наименованиях номенклатуры при оприходовании в ERP/1С.
- Сложность сопоставления списания материалов с реальными физическими захватками.

## 3. Целевой процесс
- Интеллектуальное оптическое распознавание первичных документов (УПД/ТОРГ-12) и автосопоставление с заказами снабжения.
- Автоматическая сверка списания по нормам М-29 с фактически подтверждённым монтажом.

## 4. Статус модуля
`CONCEPT`

# Коммерческий отдел (Commercial Department)

## 1. Роль подразделения в цепочке
Коммерческий отдел первым принимает удар входящей информации по новым объектам. Задача отдела — за минимальное время оценить тендерную документацию, сформировать реалистичную ведомость объёмов работ (ВОР), оценить себестоимость материалов и монтажа, выявить скрытые риски и подготовить коммерческое предложение (КП).

## 2. Ключевые проблемы (Friction Points)
- **Хаос входящих данных**: Заказчик присылает архивы без структуры, содержащие сотни файлов с техническими названиями (PDF, DWG, сканы писем).
- **Некомплектность**: Отсутствие листов фасадов, неполные спецификации заполнений, отсутствие узлов примыканий.
- **Риск занижения объёмов**: Ручной подсчёт площадей приводит к ошибкам до 10–25%, что грозит кассовыми разрывами на этапе монтажа.

## 3. Целевой процесс с прикладным ИИ
1. **Регистрация тендера и загрузка архива**: Папка с файлами принимается приложением.
2. **Индексация и распознавание форматов**: Автоматическое разделение на разделы (АР, КР, КМ, спецификации, общие пояснительные записки).
3. **Контроль версий и дедупликация**: Выявление повторных редакций чертежей.
4. **Сверка ВОР и чертежей**: Детерминированный алгоритм сопоставляет заявленные заказчиком объёмы с суммами по спецификациям.
5. **Выявление белых пятен**: ИИ подсвечивает отсутствующие данные и формирует черновик запроса на разъяснение заказчику (RFI).
6. **Контроль человеком (Human-in-the-loop)**: Инженер утверждает итоговый проект КП.

## 4. Статус модуля

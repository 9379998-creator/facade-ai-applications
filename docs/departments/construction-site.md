# Строительная площадка (Construction Site)

## 1. Роль подразделения
Монтаж кронштейнов, утеплителя, мембран, направляющих профилей, установка стоек, ригелей, монтаж тяжелых стеклопакетов с помощью вакуумных манипуляторов, герметизация и сдача технадзору.

## 2. Ключевые проблемы
- Бумажный документооборот и задержка отчётов о прогрессе монтажа.
- Монтаж конструкций с нарушением допусков по вертикали/горизонту, выявляемый на поздних этапах.
- Потеря времени на поиск нужного ящика или пирамиды на приобъектном складе.

## 3. Целевой процесс
- Мобильное приложение прораба и бригадира: сканирование элемента, отметка "смонтирован", фиксация в единой модели.
- Фотофиксация скрытых работ с мгновенной привязкой к осям и формированием черновика АОСР.

## 4. Статус модуля
`CONCEPT`

# Конструкторский отдел (Design Department)

## 1. Роль подразделения
Разработка рабочей документации стадий КМ и КМД, расчёт статических и ветровых нагрузок, раскладка элементов каркаса (стоек, ригелей, кронштейнов), деталировка узлов примыкания и формирование спецификаций для закупки и станков.

## 2. Ключевые проблемы
- Рутинная перебивка параметров из архитектурных планов в расчётные комплексы.
- Риск расхождений между геометрией витража и спецификацией стеклопакетов.
- Длительный поиск коллизий на стыках разных фасадных подсистем (например, витраж и кассетная облицовка).

## 3. Целевой процесс
- Автоматизированная проверка спецификаций на геометрическую связность.
- Автогенерация карт раскроя профиля и листовых материалов с оптимизацией отхода.
- Детерминированный контроль соответствия СП и ГОСТ по ветровым нагрузкам на отметках.

## 4. Статус модуля
`CONCEPT`

# Финансово-экономическая служба (Finance Department)

## 1. Роль подразделения
Бюджетирование объекта, контроль план-факт себестоимости материалов и СМР, казначейство, управление дебиторской и кредиторской задолженностью, предотвращение кассовых разрывов.

## 2. Ключевые проблемы
- Разрыв между физическим объёмом выполненных работ на фасаде и закрытыми актами КС-2 / КС-3.
- Непредвиденные затраты на переделки и дополнительный крепёж, "размывающие" маржу проекта.
- Запоздалая управленческая отчётность (данные о рентабельности поступают через месяц после закрытия периода).

## 3. Целевой процесс
- Автоматическая сверка смонтированных на площадке площадей с реестром актования.
- Мониторинг фактической себестоимости фасада на 1 м² в динамике.

## 4. Статус модуля
`CONCEPT`

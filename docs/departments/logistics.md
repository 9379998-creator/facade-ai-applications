# Служба логистики (Logistics Department)

## 1. Роль подразделения
Координация поставок материалов на центральный склад, перемещение в цех обработки и доставка готовых комплектов и крупногабаритных стеклопакетов на стройплощадку точно в срок (Just-in-Time).

## 2. Ключевые проблемы
- Стеснённые условия городской застройки (отсутствие площадок для долгосрочного складирования).
- Привоз конструкций не под ту захватку, которая сейчас монтируется, приводящий к порче элементов.
- Сложность сверки упаковочных листов и транспортных накладных при разгрузке.

## 3. Целевой процесс
- Генерация партий отгрузки по захваткам на основе цифрового графика площадки.
- QR-маркировка пирамид со стеклопакетами и паллет с кассетами.

## 4. Статус модуля

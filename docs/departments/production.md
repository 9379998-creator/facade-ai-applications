# Производство (Production Department)

## 1. Роль подразделения
Обработка алюминиевого профиля (пиление, фрезеровка, сверление), сборка элементов витражей, гибка и фрезеровка кассет из листового композита и алюминия, наклейка уплотнителей, контроль геометрии.

## 2. Ключевые проблемы
- Изготовление изделий по старым ревизиям КМД при внесении правок архитектором.
- Простои дорогостоящих ЧПУ-центров из-за отсутствия готовых технологических карт.
- Брак при сборке угловых стыков и установке термомостов.

## 3. Целевой процесс
- Экраны рабочих мест с актуальными чертежами конкретной детали по штрихкоду.
- Автоматический контроль соответствия партии допускам при выпуске из цеха.

# Руководитель проекта (Project Management)

## 1. Роль подразделения
Сквозное оперативное и стратегическое управление объектом: контроль сроков по мастер-графику, бюджета, координация генподрядчика, смежников и всех внутренних отделов фасадной компании.

## 2. Ключевые проблемы
- "Слепые зоны" между передачей документации и поставками на площадку.
- Позднее выявление срывов критического пути (Critical Path).
- Трата десятков часов в неделю на ручной сбор сводных отчётов для заказчика.

## 3. Целевой процесс
- Сводный дашборд прогресса объекта в реальном времени (по захваткам, ярусам и фасадам).
- Предиктивные предупреждения: автоматический расчёт риска срыва сдачи яруса при задержке партии профиля или стеклопакетов.

## 4. Статус модуля
`CONCEPT`

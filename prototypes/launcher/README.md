# Прототип просмотрщика документации Launcher

## Концепция
Интегрированный в платформу легковесный просмотрщик инженерной документации для специалистов, которым не требуется полнофункциональный и тяжёлый CAD-комплекс (сметчики, снабженцы, юристы, прорабы на площадке).

## Статус
`PROTOTYPE` (интерактивный демонстрационный сценарий без зависимости от внешних закрытых кодовых баз).

## Файлы спецификации прототипа
- `scenario.md` — пользовательский сценарий работы с документами.
- `shot-list.md` — перечень экранов и демонстрационных ракурсов.
- `integration-plan.md` — план интеграции с единой моделью данных проекта.
- `demo-manifest.json` — манифест демонстрационных файлов и статусов их отображения.

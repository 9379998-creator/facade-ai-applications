# План интеграции просмотрщика Launcher

1. **Изоляция исходного кода**:
   - Исходный код сторонних прототипов (включая `fero-launcher-v4`) в данный репозиторий **не копируется**.
2. **Интерфейс взаимодействия (API Contract)**:
   - Легковесный модуль веб-просмотра встраивается как независимый React-компонент, принимающий URL или File/Blob векторного документа.
3. **Обработка статусов рендеринга**:
   - `IDLE` -> `LOADING` -> `RENDERED` / `ERROR`.
   - В случае ошибки повреждённого файла отображается понятное сообщение с рекомендацией открыть документ в нативном приложении.

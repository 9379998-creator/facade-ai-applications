# Пользовательский сценарий просмотрщика Launcher

1. **Инициализация и выбор комплекта**:
   - Пользователь открывает раздел объекта (например, «Северный порт»).
   - В левой панели отображается единое древовидное пространство папок и файлов.
2. **Навигация по форматам**:
   - При клике на файл формата PDF или DWG система открывает предварительный просмотр.
   - Пользователь может переключаться между листами чертежа.
3. **Масштабирование и инспекция**:
   - Поддерживается плавное панорамирование (pan) и масштабирование (zoom).
   - Инструмент выделения штампа позволяет мгновенно проверить ревизию и дату согласования.
4. **Обновление и статус рендеринга**:
   - Если файл был обновлён, интерфейс подсвечивает индикатор ревизии.

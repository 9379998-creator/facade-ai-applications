# Синтетический проект «Северный порт» (Northern Port)

Данный каталог содержит безопасные обезличенные данные синтетического демонстрационного объекта «Северный порт», используемого во всех презентациях и модулях приложения.

## Структура каталога
- `passport.md` — архитектурный и инженерный паспорт объекта.
- `assumptions.md` — принятые синтетические допущения.
- `open-questions.md` — открытые вопросы и поля со статусом TBD.
- `participants.json` — вымышленные участники проекта и роли.
- `facade-systems.json` — состав применяемых фасадных подсистем и материалов.
- `document-register.json` — синтетический реестр входящей документации.
- `zones.json` — захватки и фасадные зоны объекта.
- `work-breakdown.json` — иерархическая структура работ (WBS).
- Подкаталоги отделов (`commercial/`, `design/`, `procurement/`, и др.) — специализированные синтетические данные.
